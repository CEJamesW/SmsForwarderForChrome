## SmsForwarderForChrome - 验证码自动提取与填充功能

为 Chrome 扩展 SmsForwarderForChrome（Manifest V3）添加了验证码自动提取和自动填充功能。

### 变更文件
- **新增 `shared/codeutil.js`**: 验证码正则提取工具，支持中英文关键词（验证码/校验码/code/otp等）+ 4-8位数字，支持自定义正则
- **修改 `background.js`**:
  - importScripts 引入 codeutil.js
  - mergeAndStoreSmsList 中对新短信提取验证码，调用 tryAutoFillCode 注入页面
  - tryAutoFillCode: 获取活动标签页 → executeScript 注入 fillCodeInPage 函数
  - fillCodeInPage: 评分系统检测验证码输入框（autocomplete=one-time-code > 关键词匹配 > maxlength/inputmode），使用 native setter 填充（兼容 React/Vue），触发 input/change 事件，绿色边框闪烁反馈
  - notifyNewSms 增强：标题显示验证码，双按钮（复制验证码/复制短信）
  - storeNotificationPayload/readNotificationPayload 增加 code 字段
- **修改 `options.html`**: 新增"验证码自动填充"设置区（开关 + 自定义正则输入框 + 保存按钮）
- **修改 `options.js`**: loadCodeSettings/saveCodeSettings 函数，含正则有效性验证
- **修改 `sidepanel.html`**: 引入 codeutil.js，新增验证码徽章 CSS 样式
- **修改 `popup.js`**: buildCodeRowHtml 生成验证码行，window.copyCodeToClipboard 复制函数，本地和服务端两条渲染路径均插入验证码行

### 技术要点
- Chrome MV3 service worker 使用 importScripts 加载共享脚本
- executeScript func 必须自包含，不能引用外部变量
- 使用 Object.getOwnPropertyDescriptor 获取原生 value setter 以兼容 React/Vue
- 验证码检测优先级: autocomplete=one-time-code > 关键词属性匹配(3分) > label文本匹配(3分) > maxlength 4-8(2分) > inputmode numeric(1分) > 父元素文本(1分)，阈值 >= 2
